About Blandis

Last updated: 1 November 2026

The project

Blandis is a free browser game: pick, launch, squish and merge soft numbered blobs up to 2048. It has an optional public leaderboard of high scores. New to the game? Read how to play Blandis (en español).

It is a personal, non-commercial project. It does not sell anything, show advertising, have sponsors or generate any income.

What's in the game

Every blob in Blandis is a soft ring that squashes, bulges and fills the gaps around it, so no two rounds play out the same way. Equal numbers that touch merge into their double, from 2 all the way to 2048. There are five game modes (Classic, Time attack, Speedrun, Sprint 512 and 40 shots), each with its own best scores and its own global leaderboard, more than 70 achievements, seven unlockable color styles and the option to put your own picture inside the jar. The game is available in English and Spanish and works with a mouse, a touchscreen or a keyboard.

How it's built

Blandis is written in plain JavaScript and drawn on an HTML canvas, with no game engine or framework. The physics is a small position-based soft-body solver written for this game: each blob is a ring of points pulled back toward a circle by shape matching, keeps its area so it behaves like a cushion rather than a balloon, and collides with the jar and with the other blobs. It runs at a fixed time step, so the game plays at the same speed on fast and slow devices.

The site is static and served by GitHub Pages; the source code is bundled into a single file on every release. The optional global leaderboard runs on Cloudflare Workers with a small database in the EU. The Nunito font is self-hosted, so no visitor data is sent to a font service, and Google Analytics only loads if you accept it.
